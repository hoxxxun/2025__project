# Fortune For You - 사주 기반 소개팅 웹사이트

## 프로젝트 개요

사주 정보를 기반으로 사용자 간의 궁합을 분석하고 매칭해주는 소개팅 플랫폼입니다.
사용자는 자신의 사주 정보(년-월-일)를 등록하고, 시스템은 이를 분석하여 호환성 있는 사용자들을 매칭해줍니다.
또한 커뮤니티 기능과 실시간 채팅을 통해 사용자들 간의 상호작용을 지원합니다.

##주요 기능

- **회원 관리**: 사주 정보 기반 프로필 생성 및 관리
- **매칭 시스템**: 사주 기반 궁합 분석 및 추천
- **커뮤니티**: 게시판 및 댓글 기능
- **실시간 채팅**: Socket.IO 기반 1:1 채팅
- **보안**: 비밀번호 암호화 및 세션 관리
